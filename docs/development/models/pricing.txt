Model: Pricing
Table: pricings
Database: SQLite

Purpose
- Admin-managed price list by vehicle type.
- Booking form loads amounts from this table (not hardcoded).
- Capacity for a type lives here (shared by all fleet units of that pricing).

Fields
- id                    INTEGER PRIMARY KEY
- vehicle_type          TEXT NOT NULL UNIQUE
                        seed defaults:
                        - 6-wheeler truck
                        - 4-wheeler truck
                        - L300 van
                        - Reefer / specialized
- amount                REAL NOT NULL
                        seed defaults: 14500.00 | 9200.00 | 4500.00 | 18500.00
- capacity_kg           INTEGER NOT NULL
                        seed defaults: 12000 | 3000 | 1000 | 5000
- archived_at           TEXT NULL
- created_at            TEXT NULL
- updated_at            TEXT NULL

Relations (Eloquent)
- vehicles()            HasMany Vehicle
- bookings()            HasMany Booking

Notes
- One row per vehicle type.
- When a booking invoice is created, copy amount into Invoice.amount (commercial snapshot).
- Open-booking fare display uses Pricing until an invoice exists; billed history uses Invoice.
- Fleet units reference pricing_id; capacity is read from Pricing (not stored on vehicles).
- System Admin Pricing List module: full CRUD.
- Soft delete via archived_at.
