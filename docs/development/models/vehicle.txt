Model: Vehicle
Table: vehicles
Database: SQLite

Purpose
- Physical fleet unit. Locked to in_use when a driver accepts a booking.
- Type/price/capacity come from Pricing via pricing_id.
- Optionally assigned to one driver (admin Fleet / Users forms).

Fields
- id                    INTEGER PRIMARY KEY
- plate_number          TEXT NOT NULL UNIQUE
- brand                 TEXT NOT NULL
- color                 TEXT NULL
- pricing_id            INTEGER NOT NULL → pricings.id
- status                TEXT NOT NULL DEFAULT 'available'
                        values: available | in_use | maintenance
- driver_id             INTEGER NULL UNIQUE → users.id (role driver)
                        Optional assigned driver; one vehicle per driver.
- archived_at           TEXT NULL
- created_at            TEXT NULL
- updated_at            TEXT NULL

Relations (Eloquent)
- driver()              BelongsTo User (driver_id)
- pricing()             BelongsTo Pricing
- bookings()            HasMany Booking
- Accessor type: pricing.vehicle_type (display)

Notes
- Capacity is on Pricing (pricing.capacity_kg), not on this table.
- Assign/unassign via admin Fleet or User forms (vehicles.driver_id only).
- On driver accept: prefer driver's assigned vehicle when pricing matches;
  else any available unit with the same pricing_id; set status = in_use.
- On booking completed/cancelled (when releasing): status = available if it was in_use.
- Soft delete via archived_at (System Admin only); clear driver_id before archive.
