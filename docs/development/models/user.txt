Model: User
Table: users
Database: SQLite

Purpose
- Single identity for all roles (customer, driver, staff, system_admin).
- Replaces legacy split of customers / drivers / admins / users tables.

Fields
- id                    INTEGER PRIMARY KEY
- name                  TEXT NOT NULL
- email                 TEXT NOT NULL UNIQUE
- email_verified_at     TEXT NULL (datetime; required for login after register)
- password              TEXT NOT NULL (hashed)
- mobile                TEXT NULL (contact number; shown to customers for assigned drivers after accept)
- avatar_path           TEXT NULL (private disk path; profile photo for all roles)
- role                  TEXT NOT NULL
                        values: customer | driver | staff | system_admin
- remember_token        TEXT NULL
- archived_at           TEXT NULL (soft delete; null = active)
- created_at            TEXT NULL
- updated_at            TEXT NULL

Relations (Eloquent)
- customerBookings()    HasMany Booking (customer_id)
- driverBookings()      HasMany Booking (driver_id)
- assignedVehicle()     HasOne Vehicle (vehicles.driver_id)
- activityLogs()        HasMany ActivityLog

Notes
- Driver self-register: identity only (no vehicle fields). Fleet assignment is optional
  and done by admin (Fleet create/edit or User create/edit vehicle dropdown).
- Driver plate / type / capacity come from assignedVehicle → Pricing (no denormalized
  copies on users).
- Without an assigned vehicle, driver cannot see/accept matching jobs (pricing_id match).
- Customer and Driver self-register; Staff is created by System Admin.
- Soft delete via archived_at (Admin only); clear fleet assignment when archiving a driver.
