Model: Pod
Table: pods
Database: SQLite

Purpose
- Proof of Delivery: photos on the completed status.
- One POD record per booking (1:1), may store multiple photo paths.

Fields
- booking_id            INTEGER PRIMARY KEY  → bookings.id
- photo_paths           TEXT NOT NULL        (JSON array of private storage paths)
- captured_at           TEXT NOT NULL
- archived_at           TEXT NULL
- created_at            TEXT NULL
- updated_at            TEXT NULL

Notes
- Captured when delivery reaches completed (driver on active delivery details).
- System Admin can CRUD.
- Soft delete via archived_at.
- SQLite: store photo_paths as JSON text; decode in the app.
